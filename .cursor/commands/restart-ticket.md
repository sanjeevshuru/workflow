# restart-ticket

Force the ticket workflow to restart. The first word after the command is the Jira key; any further words are Figma links.

Read `flow/ORCHESTRATOR.md` → **Restart (forced)** and follow it exactly: move the old run to `runs/_archive/`, then start from step 01 and continue through every step, as `/run-ticket` does. Run roles sequentially in this chat.
